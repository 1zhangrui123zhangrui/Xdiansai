# F407_main — 绳驱巡检装置主控 (STM32F407VET6)

## 一、系统架构

```
┌──────────────────────────────────────────────────────┐
│  STM32F407VET6                                       │
│                                                      │
│  USART1 ──► ZDT X42S ×4  (RS-485/TTL 多机控制)      │
│  USART2 ──► 串口屏        (HMI)                      │
│  SPI1   ──► NRF24L01     (接收 F103 视觉数据)        │
│  PB8    ──► 蜂鸣器        (火源报警)                 │
└──────────────────────────────────────────────────────┘
          ↑↓ NRF24L01 (2.4GHz)
┌──────────────────────────────────────────────────────┐
│  STM32F103C8T6 (平台)                                │
│  摄像头 → 识别火源 + 位置偏差 → 打包 NRF 发送        │
└──────────────────────────────────────────────────────┘
```

## 二、文件结构

```
Core/
├── App/
│   ├── platform_config.h   # 所有硬件/机械参数宏 (调参入口)
│   ├── motor.h / .c        # ZDT X42S 电机驱动
│   ├── kinematics.h / .c   # 绳驱运动学
│   ├── task.h / .c         # 任务状态机
│   ├── screen.h / .c       # 串口屏驱动
│   ├── nrf_app.h / .c      # NRF 应用层
│   └── buzzer.h / .c       # 蜂鸣器
├── NRF24L01/
│   ├── 24l01.h / .c        # NRF24L01 底层驱动
├── Src/main.c              # 主程序入口
```

## 三、硬件引脚分配

| 功能         | 引脚           | 说明                        |
|------------|--------------|---------------------------|
| USART1 TX  | PA9          | → 电机 (1/2/3/4 并联总线)  |
| USART1 RX  | PA10         | ← 电机应答                  |
| USART2 TX  | PA2          | → 串口屏                    |
| USART2 RX  | PA3          | ← 串口屏                    |
| SPI1 SCK   | PA5          | NRF24L01                  |
| SPI1 MISO  | PA6          | NRF24L01                  |
| SPI1 MOSI  | PA7          | NRF24L01                  |
| NRF CE     | PA8          | GPIO Output               |
| NRF CSN    | PC9          | GPIO Output               |
| NRF IRQ    | PC8          | GPIO Input                |
| 蜂鸣器      | PB8          | **需在 IOC 中新增 GPIO Output** |

> ⚠️ 蜂鸣器 PB8 尚未在 CubeMX IOC 中配置，需要在 IOC 添加后重新生成。
> 在 `platform_config.h` 中修改 `BUZZER_GPIO_PORT/PIN` 以匹配实际引脚。

## 六、关键参数调整 (`platform_config.h`)

| 参数               | 说明                         | 默认值    |
|------------------|----------------------------|--------|
| `ROPE_H_CM`      | 滑轮顶部到平台竖直距离 (cm)   | 2.5    |
| `SPOOL_RADIUS_CM`| 绕线轮半径 (cm)，直径 3.5cm | 1.75   |
| `LASER_OFFSET_X_CM` | 激光点相对平台中心 X 偏移 (cm) | 3.5    |
| `MOTOR_SPEED_RPM` | 最大速度 (RPM)              | 10     |
| `MOTOR_ACCEL_RPMS`  | 加速加速度 (RPM/S)          | 10     |
| `MOTOR_DECEL_RPMS`  | 减速加速度 (RPM/S)          | 10     |
| `MOTOR_MOVE_TIMEOUT_MS` | 运动超时 (ms)           | 30000  |

> **上电前必须先把激光点手动放在中心圆。** F407 上电后会立刻把当前位置清零为 0 度，然后关闭使能保持松轴；按「启动」后再使能并同步回 0 度。
> 激光点在中心圆 `(0,0)` 时，平台中心按 `(-3.5, 0)` 参与绳长计算，四个挂点再相对平台中心偏移 `±5cm`。

当前暂时关闭开环坐标标定补偿，先以真实高度和机械张紧状态为准；补偿参数保留在 `platform_config.h` 的 `KINEMATICS_CALIB_*` 中。


## 七、NRF 数据包协议 (F103→F407, 8 字节)

```
Byte 0: flags  (bit0=检测到火源, bit1=位置数据有效)
Byte 1: seq    (序列号, 调试用)
Byte 2-3: dx   (int16, 0.1mm, 摄像头偏离指令中心的 X 误差)
Byte 4-5: dy   (int16, 0.1mm)
Byte 6: fire_x (int8, cm, 火源 X 坐标)
Byte 7: fire_y (int8, cm, 火源 Y 坐标)
```

F103 端需要将数据按照 `NRF_CamData_t` 结构打包后发送 (见 `nrf_app.h`)。

## 八、串口屏命令 (已完成, 见串口屏.md)

| 按钮      | 命令码  | 动作            |
|---------|--------|----------------|
| 启动     | 0xA1   | 回中心          |
| 区域巡逻 | 0xA2   | 四角依次        |
| 顺序巡逻 | 0xA3   | 用户指定 5 圆顺序 |
| 自动巡逻 | 0xA4   | 蛇形路径+火源检测 |
| 标定     | 0xA5   | 电机位置清零    |
| 返回/急停 | 0xA0  | 立即停止        |

## 九、首次使用步骤

1. 在 CubeMX IOC 中为蜂鸣器新增 GPIO Output 引脚 (推荐 PB8)，重新生成代码。
2. 修改 `platform_config.h` 中 `ROPE_H_CM`、`SPOOL_RADIUS_CM` 为实测值。
3. 将平台手动放置到中心位置后再给 F407 上电，等待上电清零并松轴。
4. 评委可手动拉开平台；按串口屏「启动」按钮，观察平台是否使能后同步回中心。
5. 逐步测试区域巡逻、顺序巡逻、自动巡逻。
