# 串口屏通信方案（最终版）

## 二、屏端改动

### 2.1 统一控件命名

每个页面上显示坐标的文本控件，objname 必须统一：

|页面|X 坐标控件 objname|Y 坐标控件 objname|
|---|---|---|
|首页 (page 0)|`tX`|`tY`|
|启动页面 (page 1)|`tX`|`tY`|
|区域巡逻 (page 2)|`tX`|`tY`|
|顺序巡逻 (page 3)|`tX`|`tY`|
|自动巡逻 (page 4)|`tX`|`tY`|
|火源坐标显示 (page 5)|`tX`|`tY`|

不同页面可以有同名控件，屏不带页面前缀时只在当前页面查找。

### 2.2 火源坐标显示页的额外控件

在火源坐标显示页面（page 5）上额外放 4 个文本控件：

|控件|objname|用途|初始值|
|---|---|---|---|
|火源1 X 坐标|`tF1X`|第1个火源的X|`--`|
|火源1 Y 坐标|`tF1Y`|第1个火源的Y|`--`|
|火源2 X 坐标|`tF2X`|第2个火源的X|`--`|
|火源2 Y 坐标|`tF2Y`|第2个火源的Y|`--`|

### 2.3 每个页面的后初始化事件

每个页面的**后初始化事件**里加页码上报，告诉单片机当前在哪一页：

**首页：**

```

```

**启动页面：**

```

prints 0xB1,1
```

**区域巡逻：**

```

```

**顺序巡逻：**

```

prints 0xB3,1
```

**自动巡逻：**

```

```

**火源坐标显示：**

```

prints 0xB5,1
```

### 2.4 按钮事件

所有按钮的弹起事件里，**prints 必须放在 page 跳页之前**，否则跳页后 prints 可能不执行。

**启动按钮 b0（首页）：**

```

```

**区域巡逻按钮 b1（首页）：**

```

**顺序巡逻按钮 b2（首页）：**

```

```

**自动巡逻按钮 b3（首页）：**

```
prints "UU",0

```

```

## 三、通信协议

### 3.1 屏 → 单片机（命令码）

帧格式：`0x55 0x55 + CMD`

|命令|码值|说明|
|---|---|---|
|返回/急停|`0xA0`|停止当前任务|
|启动|`0xA1`|回到中心区域|
|区域巡逻|`0xA2`|四角依次巡逻|
|顺序巡逻|`0xA3`|后跟 5 字节 ASCII + 0xFE|
|自动巡逻|`0xA4`|蛇形巡逻|
|标定|`0xA5`|零点标定|

### 3.2 屏 → 单片机（页码上报）

帧格式：`0x55 0x55 + 0xBx`

|页码|码值|页面|
|---|---|---|
|0|`0xB0`|首页|
|1|`0xB1`|启动页面|
|2|`0xB2`|区域巡逻|
|3|`0xB3`|顺序巡逻|
|4|`0xB4`|自动巡逻|
|5|`0xB5`|火源坐标显示|

### 3.3 单片机 → 屏（实时坐标）

ASCII 指令 + 3 个 0xFF 结束符，**不带页面前缀**：

```
tX.txt="12.34" FF FF FF
tY.txt="-5.67" FF FF FF
```

每 100ms 发一次，屏自动更新当前页面上叫 `tX` / `tY` 的控件。

### 3.4 单片机 → 屏（火源坐标）

检测到火源时发一次，或用户切到火源页面时补发：

```
tF1X.txt="20.15" FF FF FF
tF1Y.txt="-10.30" FF FF FF
tF2X.txt="5.50" FF FF FF
tF2Y.txt="18.20" FF FF FF
```

### 4.2 screen.c

```c
#include "screen.h"
#include <string.h>
#include <stdio.h>

/* ========== 内部状态 ========== */
static UART_HandleTypeDef *s_huart = NULL;
static uint8_t s_rx_byte = 0;
static uint8_t s_current_page = 0;

/* 火源记录 */
static float s_fire_x[2] = {0};
static float s_fire_y[2] = {0};
static uint8_t s_fire_count = 0;

/* 回调表 */
#define MAX_CMD_CALLBACKS 8
typedef struct {
    uint8_t cmd;
    ScreenCmdCallback_t cb;
} CmdEntry_t;
static CmdEntry_t s_cmd_table[MAX_CMD_CALLBACKS];
static uint8_t s_cmd_count = 0;
static ScreenSeqCallback_t s_seq_callback = NULL;

/* 接收状态机 */
typedef enum {
    RX_WAIT_HEAD1,
    RX_WAIT_HEAD2,
    RX_WAIT_CMD,
    RX_WAIT_SEQ,
} RxState_t;
static RxState_t s_rx_state = RX_WAIT_HEAD1;
static uint8_t s_seq_buf[5];
static uint8_t s_seq_idx = 0;

static const uint8_t SCREEN_END[3] = {0xFF, 0xFF, 0xFF};

/* ========== 内部函数 ========== */

static void Screen_SendRaw(const char *str)
{
    HAL_UART_Transmit(s_huart, (uint8_t *)str, strlen(str), 100);
    HAL_UART_Transmit(s_huart, (uint8_t *)SCREEN_END, 3, 100);
}

static void Screen_DispatchCmd(uint8_t cmd)
{
    for (uint8_t i = 0; i < s_cmd_count; i++) {
        if (s_cmd_table[i].cmd == cmd && s_cmd_table[i].cb != NULL) {
            s_cmd_table[i].cb();
            return;
        }
    }
}

/* 把已记录的火源坐标发送到屏(切到火源页面时调用) */
static void Screen_FlushFire(void)
{
    char buf[32];
    for (int i = 0; i < s_fire_count; i++) {
        snprintf(buf, sizeof(buf), "tF%dX.txt=\"%.2f\"", i + 1, s_fire_x[i]);
        Screen_SendRaw(buf);
        snprintf(buf, sizeof(buf), "tF%dY.txt=\"%.2f\"", i + 1, s_fire_y[i]);
        Screen_SendRaw(buf);
    }
}

/* ========== 对外接口 ========== */

void Screen_Init(UART_HandleTypeDef *huart)
{
    s_huart = huart;
    s_cmd_count = 0;
    s_seq_callback = NULL;
    s_rx_state = RX_WAIT_HEAD1;
    s_current_page = 0;
    s_fire_count = 0;
    HAL_UART_Receive_IT(s_huart, &s_rx_byte, 1);
}

void Screen_RegisterCallback(uint8_t cmd, ScreenCmdCallback_t callback)
{
    for (uint8_t i = 0; i < s_cmd_count; i++) {
        if (s_cmd_table[i].cmd == cmd) {
            s_cmd_table[i].cb = callback;
            return;
        }
    }
    if (s_cmd_count < MAX_CMD_CALLBACKS) {
        s_cmd_table[s_cmd_count].cmd = cmd;
        s_cmd_table[s_cmd_count].cb = callback;
        s_cmd_count++;
    }
}

void Screen_RegisterSequenceCallback(ScreenSeqCallback_t callback)
{
    s_seq_callback = callback;
}

uint8_t Screen_GetCurrentPage(void)
{
    return s_current_page;
}

/*
 * 实时坐标更新
 * 直接写当前页面上叫 tX / tY 的文本控件
 * 不带页面前缀,屏自动在当前页面查找
 * 由 main 循环每 100ms 调用一次
 */
void Screen_SetCoord(float x, float y)
{
    char buf[32];
    snprintf(buf, sizeof(buf), "tX.txt=\"%.2f\"", x);
    Screen_SendRaw(buf);
    snprintf(buf, sizeof(buf), "tY.txt=\"%.2f\"", y);
    Screen_SendRaw(buf);
}

/*
 * 记录火源坐标
 * 检测到火源时调用一次,最多记录 2 个
 * 数据存在单片机内存里,切到火源页面时自动发送
 * 如果当前就在火源页面,立刻发送
 */
void Screen_RecordFire(float x, float y)
{
    if (s_fire_count >= 2) return;
    s_fire_x[s_fire_count] = x;
    s_fire_y[s_fire_count] = y;
    s_fire_count++;

    /* 如果当前就在火源页面(page 5),立刻刷新 */
    if (s_current_page == 5) {
        Screen_FlushFire();
    }
}

void Screen_SetText(const char *objname, const char *text)
{
    char buf[64];
    snprintf(buf, sizeof(buf), "%s.txt=\"%s\"", objname, text);
    Screen_SendRaw(buf);
}

/* ========== 接收状态机 ========== */

void Screen_OnByteReceived(uint8_t byte)
{
    switch (s_rx_state) {
    case RX_WAIT_HEAD1:
        if (byte == 0x55) s_rx_state = RX_WAIT_HEAD2;
        break;

    case RX_WAIT_HEAD2:
        if (byte == 0x55) {
            s_rx_state = RX_WAIT_CMD;
        } else {
            s_rx_state = RX_WAIT_HEAD1;
        }
        break;

    case RX_WAIT_CMD:
        if (byte >= 0xB0 && byte <= 0xBF) {
            /* 页码上报:屏告诉单片机当前在第几页 */
            s_current_page = byte - 0xB0;
            /* 切到火源页面时,补发已记录的火源坐标 */
            if (s_current_page == 5) {
                Screen_FlushFire();
            }
            s_rx_state = RX_WAIT_HEAD1;
        } else if (byte == CMD_SEQ_PATROL) {
            /* 顺序巡逻命令,后面跟 5 字节 ASCII + 0xFE */
            s_seq_idx = 0;
            s_rx_state = RX_WAIT_SEQ;
        } else {
            /* 其他简单命令(启动/区域/自动/返回/标定) */
            Screen_DispatchCmd(byte);
            s_rx_state = RX_WAIT_HEAD1;
        }
        break;

    case RX_WAIT_SEQ:
        if (byte == 0xFE) {
            /* 帧结束,校验并派发 */
            if (s_seq_idx == 5 && s_seq_callback != NULL) {
                uint8_t seq[5];
                uint8_t valid = 1;
                for (int i = 0; i < 5; i++) {
                    if (s_seq_buf[i] >= '1' && s_seq_buf[i] <= '5') {
                        seq[i] = s_seq_buf[i] - '0';
                    } else {
                        valid = 0;
                        break;
                    }
                }
                if (valid) {
                    s_seq_callback(seq);
                }
            }
            s_rx_state = RX_WAIT_HEAD1;
        } else if (s_seq_idx < 5) {
            s_seq_buf[s_seq_idx++] = byte;
        } else {
            /* 数据超长,丢弃 */
            s_rx_state = RX_WAIT_HEAD1;
        }
        break;
    }
}

/* ========== HAL 中断回调 ========== */

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart == s_huart) {
        Screen_OnByteReceived(s_rx_byte);
        HAL_UART_Receive_IT(s_huart, &s_rx_byte, 1);
    }
}
```

## 五、数据流总图

### 5.1 实时坐标

```
单片机主循环 每100ms
  ↓
Screen_SetCoord(x, y)
  ↓
发送 tX.txt="12.34" + FF FF FF  (不带页面前缀)
  ↓
屏在当前页面查找 tX 控件 → 立刻更新显示
```

### 5.2 屏按钮命令

```
用户按"启动"按钮
  ↓
屏发送 55 55 A1 (prints 在 page 之前执行)
  ↓
屏跳转到 page 1
  ↓
page 1 后初始化事件发送 55 55 B1 (页码上报)
  ↓
单片机收到 A1 → 触发 on_start 回调
单片机收到 B1 → 记录 current_page = 1
```

### 5.3 火源坐标

```
蛇形巡逻中,nRF 收到 fire_flag=1
  ↓
task.c: 停车 → 蜂鸣器响3声
  ↓
Screen_RecordFire(x, y)  // 存在单片机内存里
  ↓
如果当前在火源页 → 立刻发送 tF1X.txt="xx" 
如果当前不在      → 存着不发
  ↓
用户稍后切到火源页面
  ↓
屏发 55 55 B5 → 单片机收到 → Screen_FlushFire()
  ↓
发送 tF1X/tF1Y/tF2X/tF2Y → 屏显示
```

## 七、注意事项

1. **按钮事件里 prints 必须在 page 之前**，否则跳页后 prints 可能不执行
2. **每个页面的坐标文本控件必须叫 `tX` 和 `tY`**，名字不一致会导致赋值无效
3. **火源坐标存在单片机内存里**，最多 2 个，掉电丢失
4. **单片机发坐标不要太快**，100ms 一次（10Hz）足够，太快会撑爆屏的串口缓冲
5. **屏的波特率和单片机必须一致**，都是 115200
6. **不再需要全局变量控件、定时器、前初始化赋值**，可以全部删掉简化工程
