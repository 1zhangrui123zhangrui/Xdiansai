# 串口屏通信方案

本文档说明串口屏上位机工程应该怎么配置，和 F407 当前代码保持一致。

## 1. 串口参数

串口屏连接 F407 的 USART2：

```text
屏幕 TX -> F407 PA3 / USART2_RX
屏幕 RX -> F407 PA2 / USART2_TX
GND     -> GND
```

波特率保持和 STM32 工程一致，当前为 `115200`。

## 2. 基本协议

屏幕发给 MCU：

```text
0x55 0x55 CMD
```

在串口屏上位机里用 `prints` 写：

```text
prints "UU",0
prints 0xA1,1
```

说明：

- `"UU"` 的 ASCII 正好是两个 `0x55`，作为帧头；
- 第二行发送 1 个命令字节；
- 不要发送字符串 `"55 55 A1"`，必须发送真实字节。

MCU 发给屏幕：

```text
tX.txt="12.34" FF FF FF
tY.txt="-5.67" FF FF FF
```

所有页面上显示实时坐标的文本控件都命名为 `tX` 和 `tY`。

## 3. 当前按钮命令

| 功能 | 命令码 | 按钮事件写法 |
| --- | --- | --- |
| 返回/急停 | `0xA0` | `prints "UU",0` + `prints 0xA0,1` |
| 启动/回中 | `0xA1` | `prints "UU",0` + `prints 0xA1,1` |
| 区域巡逻 | `0xA2` | `prints "UU",0` + `prints 0xA2,1` |
| 顺序巡逻 | `0xA3` | `prints "UU",0` + `prints 0xA3,1` |
| 自动巡逻 | `0xA4` | `prints "UU",0` + `prints 0xA4,1` |
| 电机使能/抱轴 | `0xA5` | `prints "UU",0` + `prints 0xA5,1` |
| 电机失能/松轴 | `0xA6` | `prints "UU",0` + `prints 0xA6,1` |

当前没有串口屏“零点标定”按钮。`0xA5` 不是标定，而是电机使能。中心零点是否在 F407 启动时自动记录，由代码里的 `BOOT_AUTO_ZERO_ENABLE` 控制。

## 4. 第一题回中操作流程

当前第一题“启动回中”的推荐逻辑如下：

1. 第一次建立中心零点时，手动把激光点调到中心。
2. 临时把 F407 代码里的 `BOOT_AUTO_ZERO_ENABLE` 改成 `1`，烧录一次，让程序把当前电机角度记录为 `0 度`。
3. 建立零点后，把 `BOOT_AUTO_ZERO_ENABLE` 改回 `0`。
4. 以后如果电机驱动不断电，只重新烧录/复位 F407，程序不会重新清零，中心对应的电机角度保持不变。
5. 手动把平台拉到题目要求的随机位置。
6. 在串口屏按“使能”按钮，发送：

```text
prints "UU",0
prints 0xA5,1
```

7. 电机抱轴，但不会移动，也不会重新清零。
8. 在串口屏按“启动/回中”按钮，发送：

```text
prints "UU",0
prints 0xA1,1
page 1
```

9. F407 下发四电机回到 `0 度` 的命令，激光回到中心。

注意：

- `BOOT_AUTO_ZERO_ENABLE=0` 时，F407 启动不会主动清零，也不会主动失能。
- 平台被拉到随机位置后，不要再执行清零。否则随机位置会被记录成新的 `0 度`。
- 如果电机驱动断电了，或者机械位置基准变了，需要重新按上面的步骤建立中心零点。

## 5. 页面初始化事件

每个页面的后初始化事件建议上报页码，方便 MCU 知道当前屏幕在哪一页。

首页 page 0：

```text
prints "UU",0
prints 0xB0,1
```

启动页面 page 1：

```text
prints "UU",0
prints 0xB1,1
```

区域巡逻 page 2：

```text
prints "UU",0
prints 0xB2,1
```

顺序巡逻 page 3：

```text
prints "UU",0
prints 0xB3,1
```

自动巡逻 page 4：

```text
prints "UU",0
prints 0xB4,1
```

火源坐标 page 5：

```text
prints "UU",0
prints 0xB5,1
```

## 6. 按钮事件示例

按钮事件里，`prints` 要放在 `page` 跳转之前，避免跳页后事件不继续执行。

### 启动/回中按钮

```text
prints "UU",0
prints 0xA1,1
page 1
```

### 区域巡逻按钮

```text
prints "UU",0
prints 0xA2,1
page 2
```

### 顺序巡逻按钮

```text
prints "UU",0
prints 0xA3,1
page 3
```

### 自动巡逻按钮

```text
prints "UU",0
prints 0xA4,1
page 4
```

### 电机使能按钮

```text
prints "UU",0
prints 0xA5,1
```

这个按钮只让电机抱轴，不清零、不移动。F407 执行成功后蜂鸣器响 1 声。

### 电机失能按钮

```text
prints "UU",0
prints 0xA6,1
```

这个按钮会让 F407 停止电机并失能，平台松轴。F407 执行成功后蜂鸣器响 2 声。

### 返回/急停按钮

```text
prints "UU",0
prints 0xA0,1
page 0
```

### 顺序巡逻确认按钮

假设输入框控件名为 `t1`，内容为 5 个数字，例如 `31524`：

```text
prints "UU",0
prints 0xA3,1
prints t1.txt,0
prints 0xFE,1
t1.txt=""
```

## 7. 控件命名

### 实时坐标控件

每个页面都可以放同名文本控件：

| 控件名 | 作用 |
| --- | --- |
| `tX` | 显示实时 X 坐标 |
| `tY` | 显示实时 Y 坐标 |

### 火源坐标页控件

火源坐标显示页面 page 5 额外放 4 个文本控件：

| 控件名 | 作用 |
| --- | --- |
| `tF1X` | 火源 1 的 X 坐标 |
| `tF1Y` | 火源 1 的 Y 坐标 |
| `tF2X` | 火源 2 的 X 坐标 |
| `tF2Y` | 火源 2 的 Y 坐标 |

## 8. 注意事项

1. 按钮事件中，`prints` 放在 `page` 前面。
2. 坐标文本控件必须叫 `tX` 和 `tY`。
3. `0xA5` 当前是“电机使能”，不是“零点标定”。
4. 第一题回中依赖电机驱动器内部的 `0 度` 零点；默认重烧 F407 不重新清零，中心角度保持不变。
5. `0xA6` 失能会让平台松轴，并停止当前任务。
6. MCU 每 100ms 刷新一次坐标，屏幕端不需要自己做定时刷新。
